## How to run

Requires Python 3.10+ with pandas 2.x (matplotlib is optional and only used for charts).

```bash
pip install -r ../requirements.txt
python analysis.py                # finds ../data automatically, or: python analysis.py path/to/data
python dashboard.py               # prints all dashboard tables
```

From Python:

```python
from analysis import load_data, find_data_dir
from dashboard import city_dashboard
tables = city_dashboard(*load_data(find_data_dir()))
tables["by_district"]
```

The raw CSVs are only read and never modified.

## Method notes

- **Joins:** all keys were checked for uniqueness first. Every merge is a left join with `validate=` and a separately named indicator (`sensor_match`, `weather_match`, `incident_match`). Row count stays at 13,392 after every step, and the script asserts this.
- **Severity mapping:** low = 1, moderate = 2, high = 3, critical = 4.
- **Peak hours:** 07–09 and 16–18, the six hours with the highest volume in `by_hour`. Every other hour counts as off-peak.
- **Mystery baseline:** the same hours on the six nearby weekdays (5, 6, 9, 10, 11 and 13 Nov). Weekends are excluded because their volume is about 30% lower. A second baseline, all other Thursdays, gives the same result (43.6% vs 44.0% drop).
- **Weather effect:** each reading is compared with the average for the same sensor at the same hour of day, so rush-hour speeds are never compared with overnight speeds.

## Answers in brief

**Round 1**
- 13,392 traffic rows before and after integration.
- 18 weather observations are missing, so 54 traffic rows have no weather match (3 sensors per district).
- 3 incidents refer to unknown sensors: INC-ORPHAN-001/002/003 (S-099, S-098, S-097).
- A duplicated right-hand key multiplies rows: duplicating S-001 turns 13,392 rows into 14,136. `validate="many_to_one"` raises a `MergeError` instead.

**Round 2**
- Highest volume: Central (74.6 vehicles per sensor-hour).
- Lowest speed: Old Town (30.4 km/h), though it runs at 91% of its limit.
- Busiest roads: Central Boulevard, Main Avenue and Market Street.
- Most incidents: Riverside (31).
- Highest average severity: Museum Road (2.78, from 9 incidents).
- Largest peak/off-peak gap: Central (+76.5 vehicles).

**Round 3**
- Busiest hour: 17:00.
- Lowest-speed day: Thu 12 Nov (37.4 km/h). Excluding that day, the lowest is Mon 2 Nov.
- Weekend volume is 30% lower than weekdays, with the same average speed.

**Round 4**
- Where and when: Riverside, 12 Nov, 07:00–13:00. Speed fell from 34.9 to 19.7 km/h, a 43.6% drop. Bridge Road, Quay Street and Riverbank Avenue each fell 42–44%. No other district moved more than 4%.
- Evidence:
  - Three incidents on exactly those roads at 07:00, 08:00 and 09:00: a critical multi-vehicle collision, a road closure and a signal failure.
  - The weather was clear and dry, the same as on baseline days.
  - Volume fell 20–25%, which points to lost capacity rather than extra demand.
- Limitation: logged durations end around 10:15, but speeds only recovered at 13:00. Riverside wind is a constant 12 km/h on 12 Nov, which suggests filled-in data. This shows association, not proof of cause.
